To publish free with GitHub Pages:
1. Create a new public repository on GitHub (for example: the-siud-daily).
2. Upload index.html and the assets folder, keeping the folder structure unchanged.
3. In the repository, open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. GitHub will provide a public website URL after deployment.

The anonymous suggestion form is intentionally not active yet: it needs a secure submission destination (for example, a Google Form) before students should be invited to submit messages. Once you provide that form link, it can be added. Do not print a QR code until the published website URL has been tested.
